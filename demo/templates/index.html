Six Attack Categories

Content Injection

Hidden HTML/CSS traps invisible to human eyes but readable by agents parsing page content.

Semantic Manipulation

Authority framing, urgency cues, and jailbreak prompts that exploit agent instruction-following.

Cognitive State

Exploits targeting the agent's cognitive context, working memory, or attention mechanisms.

Behavioral Control

Traps that coerce agents into performing unintended actions like data exfiltration.

Systemic

Supply-chain and infrastructure-level attacks including poisoned memory and compromised APIs.

Human-in-Loop

Attacks targeting the approval workflow by overwhelming or deceiving human supervisors.
